# Style 6 · Screen Native

**Matrix:** real screen recording / paper white / interface / steady procedural.

## Look in one sentence
A real interface doing a real thing in light greys and whites, the tension
coming from watching a search run rather than from the cut.

## Palette
| Hex | Role |
| --- | --- |
| `#FFFFFF` | Page ground. The film is bright, which no other style in the set is. |
| `#162E51` | Masthead navy. Government furniture, never decoration. |
| `#1A4480` | The stat band that carries a figure. |
| `#1B1B1B` | Body copy, and the redaction block over every owner name. |
| `#FFBE2E` | The one highlight, used on exactly one result row. |

## Typography
Public Sans throughout, the face the US Web Design System actually uses, because
the facsimile has to survive a viewer who knows these sites. Nothing is set
larger than the interface would set it. The only type this style adds is one
caption at 27 px on an ink plate.

## Shot grammar
Each shot is a different framing of the same page, computed from the measured
element box rather than a hand cropped region: stat band, whole page, field,
button, results, one row, footer. States advance in the order a real search
advances and the cursor travels between framings. State changes are hard swaps.
Never dissolve an interface.

## Rhythm spec
About 44 shots per minute. Maximum static hold 2.5 s; measured 1.77. The pace
comes from the process, so the cut can only go as fast as the search does.

## Asset recipe
100 percent hand built HTML, screenshotted per state. Zero stock, zero
generation, zero footage. The cheapest style in the set alongside Style 8.

## Cost per 10 minute episode
Generation calls: 0. About 4 hours for a convincing page, 20 minutes per extra
state, 5 hours edit.

## Three rules that must never be broken
1. No real person's result. Every owner cell is a redaction block.
2. No amount column. The only figures on screen are the ones in the script.
3. The facsimile must be generic. No state seal, no agency name, no borrowed
   layout from a real portal.

## What this style is bad at
Feeling. It has no place, no object and no weight, so it cannot carry a stake or
a consequence. It also cannot cover history: an interface can only show now.
