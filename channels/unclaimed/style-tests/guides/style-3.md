# Style 3 · Annotated Screen

## Look in one sentence
A real government page sits on screen in its own browser greys while a hand
marks it up in emerald, live, as the narration reaches each fact.

## Palette
| Hex | Role |
| --- | --- |
| `#FFFFFF` and `#EEF0F4` | The page. Untouched browser white and chrome grey. Never graded. |
| `#24365E` | The masthead navy of the official site. Comes from the page, not from us. |
| `#3AAE5C` | Every annotation: circles, arrows, underlines, label chips. The only colour we add. |
| `#07130B` | Type inside an emerald chip. |
| `#8D2013` | Comes from the page only, as the status column. Never used as an annotation. |

The page must look like a real page. Resist the urge to grade or darken it.

## Typography
The page supplies its own type. We add only Inter SemiBold label chips, 32 to
42 px on a 720 px frame, sentence case, on a solid emerald plate with 12 by
20 px padding. Chips are short: two to five words. They name what the mark
means, they do not restate the narration.

## Shot grammar
A shot is a framing of the page plus one annotation that draws itself on. The
mark is a pre rendered hand drawn stroke revealed left to right over 0.32 s by
an animated alpha mask, so it reads as being drawn rather than appearing.
An oversized cursor moves between targets on the shots where a click or a field
matters. Framing pushes 3 to 15 percent through the shot, and pushes hardest on
the payoff, where the circled area fills the frame. Cuts are hard, and each cut
either changes the framing scale or changes the page.

## Rhythm spec
About 48 shots per minute. Maximum static hold 2.5 seconds; measured 1.93.
Pauses go where the viewer needs to read: the alert box about fees, and the
circled surplus figure, both get the longest holds in the film.

## Asset recipe
100 percent screen: browser page facsimiles and document facsimiles built in
HTML and screenshotted at 2x. Annotations are seven reusable transparent PNGs.
Zero stock, zero generated imagery. Like style 1, this costs nothing per shot.

## Cost per 10 minute episode
Generation calls: 0. Stock clips: 0. Build the page facsimiles once, about
4 hours, then reuse them across the whole series. Annotation set is built once
and never rebuilt. Editing: about 5 hours, mostly aligning marks to targets.

## Three rules that must never be broken
1. The page is never graded, tinted or darkened. Its credibility is the style.
2. Emerald is ours, everything else belongs to the page. Never annotate in the
   page's own red.
3. Never annotate a field that is not really there. If the page does not show
   it, do not draw an arrow to it.

## What this style is bad at
Emotion and scale. It is a screen, so it cannot make you feel what losing a
house is like, and it cannot show a country. It is also fragile: if the
facsimile looks fake, the whole style collapses.
