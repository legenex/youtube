# PART 1B · THE ENGINE SPLIT

Three engines, three jobs. Never let one do another's work.

**Generative engines (Higgsfield, Veo via Flow or API) make pictures and motion that cannot be specified.** Objects, materials, light, shadow, the physical world of the frame. They are probabilistic. You accept a range of outcomes and check the result.

**Hyperframes composes everything that must be exact.** Type, numerals, the wordmark, the accent overlay, timing, cuts, captions, aspect reframes. It is deterministic: byte-identical HTML gives byte-identical MP4, which means renders can be content-hashed and cached, and a regression can be caught with a diff.

**The line between them is the closed palette.** UNCLAIMED specifies colour to the hex and typography to the tracking value. An image model approximates `#3AAE5C` and `tracking 120 to 150`. CSS does not approximate anything. Anything the contract states as an exact value belongs in the composition, not the prompt.

Practical consequence: **generated frames contain no text.** The image model produces the object on the ground colour and nothing else. Wordmark, episode label and spoken numerals are composed on top. This removes the single most common generation failure in this style and makes the four-word cap enforceable rather than hoped for.

**`config/palette.css`** is generated from `unclaimed.json` so the hex values exist in exactly one place:

```css
:root {
  --ground: #D8E0D6;      /* ISO background */
  --object: #F2EDDF;      /* primary objects, wordmark */
  --recess: #E0D9C8;      /* secondary objects */
  --human: #8FA8DC;       /* hands, handles, human elements */
  --recoverable: #3AAE5C; /* emerald. one object per frame, one beat per episode */
  --gone: #B5B2A8;        /* warm grey */
  --type-warm: #C9B48A;   /* numerals and labels */
}
```

RISO ships a parallel block with `--paper: #F5F0E3`, `--ink: #1F3A6E`, `--recoverable: #2E8B57`, `--fill: #C9A96A`.

**`config/unclaimed.json` holds:**
`channel_id`, `style_contract` (`ISO` default), `style_string_iso`, `style_string_riso`, `palette_iso`, `palette_riso`, `accent_rule`, `voice_id`, `wpm`, `beat_count`, `beat_seconds`, `final_beat_seconds`, `runtime`, `signoff_line`, `disclaimer_block`, `thumbnail_template_id`, `playlist_map`, `music_family`, `forbidden_phrases`.

**The single most important line in this whole pipeline:** the style string is read from config and inserted into every prompt programmatically. A model never writes, retypes or summarises it. Assert equality against the config value before any generation call fires.

# PART 3 · PROMPT 1 OF 3 · RESEARCH, GATE AND SCRIPT

```
GOAL
Take topic "<TOPIC>" from the UNCLAIMED queue and produce a complete, fact-gated,
production-ready episode file at episodes/<SLUG>/episode.md plus
episodes/<SLUG>/research.md, written to the locked UNCLAIMED format. Run the whole
job in one pass without stopping for approval.

CONTEXT FILES
Read before starting: 01-channel-bible.md, 03-research-standard.md.
Read config/unclaimed.json for signoff_line, forbidden_phrases, beat spec.

PRE-AUTHORISED DECISIONS
- Narrow an ambiguous topic to the tightest version that still has national search demand.
- Choose the green beat position yourself. Note it in the header line.
- Choose the anchor object for continuity yourself.
- Write all VOICE direction yourself. Do not ask for tone preference.
- Generate three titles, lead with your pick.
- Cut any claim that fails the gate twice and rewrite the beat around what survives.
- Where a rule varies by state, pick the mechanism explanation and state it on screen.

LOOP A · RESEARCH
For each of the six research fields in the Part 7 pack format:
  1. Query official sources first, in the standing set order.
  2. Record claim, exact figure, URL, tier, check date, scope.
  3. If a claim resolves only to SECONDARY, follow the citation chain to the
     official page. If no official page exists, mark CONTESTED.
  4. Actively search for the counterexample where the claim fails.
Retry limit: 4 query reformulations per claim. On exhaustion, mark UNSOURCED and
continue. Never invent a figure to fill a gap.
Write episodes/<SLUG>/research.md.

LOOP B · FACT GATE
Run all seven gate checks from file 03 adversarially against research.md.
Emit the gate output block.
  - On FAIL: cut or hedge the affected claims, rewrite the affected pack fields,
    rerun. Maximum 2 gate cycles.
  - After 2 failed cycles: drop the failing claims permanently, record them under
    "DROPPED" in research.md, and proceed with what passed.
STOP CONDITION: if fewer than 7 of the 11 beats can be supported by PASS-tier
claims, halt, write research.md with a HALT header naming the missing evidence,
and do not write episode.md.

LOOP C · SCRIPT
Write the 11 beats to the fixed timecodes: 00:00 through 02:30 at 15s, final beat 20s.
Target 30 to 34 words per beat, 42 to 46 on the final beat, 130 wpm.
Map beats to the seven editorial functions in file 01 section 5.
For each beat write VOICE, NARRATION and VISUAL.
Then self-check every item and regenerate any failing beat, maximum 3 attempts per beat:
  * Word count inside the band
  * Average sentence length under 14 words
  * Numbers spelled out in narration, numerals only in VISUAL and only if spoken in that beat
  * Exactly one beat carries the green marker; every other VISUAL ends "No green anywhere."
  * Anchor object appears in beat 1, returns mid-episode changed, returns in beat 11 resolved
  * VISUAL describes a still frame only: no motion, no camera, no "then" or "as"
  * VISUAL literally depicts the object the narration names in that same beat
  * Final beat ends on the exact signoff_line from config
  * No string from forbidden_phrases appears anywhere
  * No em dashes, no double hyphens
  * No rhetorical questions, no "here's the thing", no "experts say", no rule-of-three padding
  * Nothing phrased as advice to this viewer

LOOP D · ASSEMBLE FILE
Write episodes/<SLUG>/episode.md with all four sections in order:
Script · AI PRODUCTION SCRIPT · SOURCES · METADATA.
METADATA carries three titles, the description block in the fixed order from file 01,
the disclaimer block verbatim from config, tags, playlist, three thumbnail text
options, and the three Shorts cut points (number beat, turn, verification beat).

EXIT CONDITION
research.md and episode.md both written, gate verdict is PASS or PARTIAL with
dropped claims recorded, every LOOP C check passes on all 11 beats.
Print a 10 line summary: title, green beat, anchor object, claim count by tier,
dropped claims, word count per beat, and any check that required 3 attempts.
Then stop.
```

# PART 6 · WHERE AUTOMATION STOPS

Four things stay human on this channel. They are exactly what a channel-level policy review examines, and a channel that automates all four is the pattern being enforced against.

1. **Fact-checking sign-off.** The gate runs automatically. A human signs it.
2. **Legal and compliance read** on any episode touching insurance, tax, estates or benefits eligibility.
3. **Title and thumbnail iteration.** Generated in threes, chosen by a person, retested against the click baseline.
4. **Format variation between episodes.** If eleven episodes in a row use the same beat mapping and the same object grammar, the channel reads as a template. Vary deliberately.
